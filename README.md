# CoverPulse

サムネ画像と曲を入れるだけで、音に合わせて動くMVを作れるブラウザツールです。
インストール不要。画像・曲・動画はすべてブラウザの中で処理され、外部には送信されません。

**▶ 使ってみる: https://soundartzix-netizen.github.io/coverpulse/**

## できること

- サムネ画像（ドロップ / Ctrl+V）と曲（WAV / MP3 など）から 1920×1080 の MV を書き出し（MP4）
- 円形バー・波形・Studio ビジュアライザー（HALO / AURORA / STARDUST / MATRIX / PRISM）など、曲に反応する演出
- キック（低音）に合わせた揺れ・フラッシュ・ズーム
- レイヤーごとの重ね順・位置・大きさ・回転、ビート演出の効く範囲の設定
- 再生位置バー・秒数カウンター（5種）、文字、質感（フィルムノイズ・走査線など）
- テンプレート 10 種類。自分の設定を保存・書き出し・読み込み（.json）
- 作業内容の自動保存（次に開いた時に続きから）と、素材ごとのプロジェクトファイル（.coverpulse）
- 追加エフェクトパック（.cpfx、[BOOTH](https://soundartz.booth.pm) で別売り）の読み込み

## アプリとしてインストール（任意）

Chrome / Edge で開くと、アドレスバー右側のアイコンか、右側のパネルの一番下にある「📥 アプリとしてインストール」からインストールできます。
デスクトップやスタートメニューから専用ウィンドウで開け、ネットにつながっていなくても使えます。
新しいバージョンが出たときは、画面に「新しいバージョンがあります」と表示されます。

## 使い方

1. サムネ画像をドロップ
2. 曲をドロップ
3. テンプレートを選んで見た目を調整
4. 「動画を書き出す」（曲と同じ長さの時間がかかります）

## 動作環境

- PC版 Chrome / Edge（最新版）推奨
- スマホ・タブレットは非推奨
